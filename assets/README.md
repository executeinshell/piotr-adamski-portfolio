# Folder na grafiki (`assets/`)

Tutaj możesz wrzucić zakupione grafiki, ilustracje wektorowe (`.svg`, `.png`, `.webp`) lub swoje zdjęcie profilowe:
- `hero-graphic.svg` / `profile.jpg` – główna grafika w sekcji Hero (prawa kolumna na górze strony)
- Dodatkowe ikony, tła lub ilustracje do sekcji `Expertise`
