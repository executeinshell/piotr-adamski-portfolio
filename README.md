# Piotr Adamski — Personal Website & Engineering Portfolio

Personal website and engineering leadership portfolio for **Piotr Adamski** (Software Engineering Manager @ Motorola Solutions).

## Tech Stack
- **HTML5** & **Tailwind CSS** (Dark/Light mode support)
- **Vanilla JavaScript** (Theme persistence, scroll reveal animations, clipboard integration)
- **Lucide Icons** & **Google Fonts** (`Inter` & `JetBrains Mono`)

## Local Preview
Simply open `index.html` in any modern web browser.
